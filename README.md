# MyGains

## Nederlands

Personal fitness app. Geen blaats. Gewoon reps en logging van gebruikte gewichten.

### Download

Download de laatste versie via [Releases](https://github.com/DispLighter/MyGains/releases/latest).

### Functies

- Sets, herhalingen en gewichten per oefening en apparaat loggen
- Voortgang en gains bekijken
- Geschiedenis van trainingen inzien
- Weet welke spiergroep je vandaag moet trainen

### Installatie

1. Download de APK via de link hierboven
2. Sta op je apparaat installatie vanuit onbekende bronnen toe
3. Open het APK-bestand en rond de installatie af

## English

Personal fitness app. No fluff. Just reps and weight logging.

### Download

Download the latest version via [Releases](https://github.com/DispLighter/MyGains/releases/latest).

### Features

- Log sets, repetitions, and weights per exercise and machine
- View progress and gains
- See workout history
- Know which muscle group to train today

### Installation

1. Download the APK via the link above
2. Allow installation from unknown sources on your device
3. Open the APK file and complete the installation
